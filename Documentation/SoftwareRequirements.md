# Software Requirements Specification

## Project Name

EmergencySOS – Personal Safety & Real-Time Location Sharing

## Objective

To develop an iOS application that allows users to quickly send an emergency SOS along with their current GPS location and maintain a history of emergency alerts.

## Functional Requirements

- User Registration
- User Login
- Forgot Password
- Profile Management
- Emergency Contacts
- SOS Alert
- Current Location
- Live Map
- SOS History
- Settings

## Non-Functional Requirements

- SwiftUI
- MVVM Architecture
- Firebase Authentication
- Firestore Database
- MapKit
- CoreLocation
- Dark Mode Support
