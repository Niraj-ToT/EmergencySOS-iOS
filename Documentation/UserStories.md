# User Stories

## EmergencySOS iOS Application

### Authentication

- As a new user, I want to register using my email so that I can create an account.
- As a registered user, I want to log in securely so that I can access my personal information.
- As a user, I want to reset my password if I forget it.

---

### Emergency Contacts

- As a user, I want to add trusted emergency contacts.
- As a user, I want to edit or remove emergency contacts.
- As a user, I want to view my saved emergency contacts at any time.

---

### SOS Feature

- As a user, I want to trigger an SOS alert with one tap.
- As a user, I want my live location to be shared with my emergency contacts during an emergency.
- As a user, I want the app to record the date and time of every SOS alert.

---

### Profile

- As a user, I want to update my profile information.
- As a user, I want to upload or change my profile picture.
- As a user, I want to manage my personal and emergency information.

---

### Settings

- As a user, I want to control notification preferences.
- As a user, I want to manage privacy settings.
- As a user, I want to sign out securely.

---

## Administrator (Future Scope)

- View application analytics.
- Monitor reported issues.
- Manage application updates.
